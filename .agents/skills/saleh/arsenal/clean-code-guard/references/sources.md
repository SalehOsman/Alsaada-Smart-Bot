# Sources and Bibliography

1. **Clean Code: A Handbook of Agile Software Craftsmanship** — Robert C. Martin (2008). Chapters 2 (Meaningful Names), 3 (Functions), 4 (Comments), 6 (Objects and Data Structures).
2. **Refactoring: Improving the Design of Existing Code** — Martin Fowler (2nd Edition, 2018). Definition of refactoring, code smells, function decomposition.
3. **The Pragmatic Programmer** — David Thomas & Andrew Hunt (20th Anniversary Edition, 2019). DRY principle, Orthogonality, Broken Windows.
4. **Practical Object-Oriented Design in Ruby** — Sandi Metz (2012). The Wrong Abstraction rule.
5. **A Complexity Measure** — Thomas J. McCabe (IEEE Transactions on Software Engineering, 1976). Cyclomatic complexity metrics.
6. **AI Code Quality Research (2024–2026):**
   - GitClear (2025): *Coding on Copilot: 2024 Data Shows Downward Trend in Code Quality*.
   - Spracklen et al. (USENIX Security 2025): *Package Hallucination Rates in AI Code Generation*.
   - Karpathy (2024): *Observations on LLM Error Swallowing and Silent Failure Modes*.
