# 🔔 التدفق 00.10: حوكمة وضبط سياسات إشعارات المنظومة

## الوصف الوظيفي
لوحة تحكم تفاعلية للمدير العام تتيح:
1. الفصل والاستقلال التام بين سياسات إشعارات جروبات المواقع الميدانية وجروب الإدارة العليا والتقارير التنفيذية.
2. تفعيل وتعطيل الإشعارات لكل وظيفة تشغيلية على حدة في أي من المسارين.
3. التحكم في نمط الإشعار (برنين عالي أو نمط صامت بدون إزعاج).
4. استعادة الإعدادات الافتراضية لأي مسار بنقرة واحدة.
