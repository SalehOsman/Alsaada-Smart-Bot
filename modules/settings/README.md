# ⚙️ موديول الإعدادات السيادية والإدارة العامة (`@alsaada/settings`)

موديول الإعدادات هو النواة الحاكمة للهيكل المؤسسي والإداري، وإدارة الصلاحيات، والرقابة الفنية لمنظومة السعادة سمارت بوت.

---

## 📂 التدفقات المعتمدة (12 تدفقاً معيارياً):

1. **`00.1-corporate-profile`**: الملف التعريفي للشركة وسياسات العمل الميدانية.
2. **`00.2-sites-hub`**: دليل وإدارة المواقع الميدانية والمشاريع.
3. **`00.3-job-matrix`**: مصفوفة المسميات الوظيفية والتصنيفات المهنية.
4. **`00.4-admin-profile`**: الملف الشخصي للمسؤول وتفضيلات الإشعارات.
5. **`00.5-admin-assignment`**: تعيين المشرفين وتحديد نطاق المواقع الميدانية.
6. **`00.6-ghost-mode`**: وضع المحاكاة الإدارية وتقمص الأدوار للمعاينة الميدانية.
7. **`00.7-audit-incident-vault`**: الصندوق الأسود وسجل حوادث التدقيق الجنائي.
8. **`00.8-apm-telemetry`**: قياس الأداء اللحظي والمراقبة الفنية وسرعة الاستجابة.
9. **`00.9-emergency-cache`**: ذاكرة الطوارئ واستعادة المعالجات المنقطعة.
10. **`00.10-notification-policies`**: سياسات توجيه الإشعارات وتوزيع التوبيكات.
11. **`00.11-telegram-groups`**: إدارة وتفويض مجموعات التليجرام وربطها بالمواقع.
12. **`00.12-user-rbac-management`**: دليل المستخدمين، تفويض الصلاحيات، والربط المباشر.
