# موديول الموارد البشرية وشؤون العاملين (`@alsaada/workforce`)

> موديول معتمد بموجب [الوثيقة 21](../../docs/21-mandatory-module-architecture-and-gates.md). يختص بكافة عمليات قيد، تسجيل، تصدير، وإدارة بيانات العمالة الميدانية.

---

## 1. نطاق العمل واختصاصات الموديول (Bounded Context)
- تسجيل وتعيين العمالة وتدقيق الأرقام القومية والجوازات.
- تصدير واستيراد كشوف العمالة المتقدمة بصيغة إكسيل RTL مع عزل وحجب البيانات المالية.
- إدارة بطاقات العمال الميدانية وتطبيق نطاق المواقع الجغرافية للمشرفين.
- إدارة الإجازات ومهمات الوقاية والتسويات العمالية.

---

## 2. التدفقات والشرائح العمودية (Flow Slices)
- `01.4-worker-export`: تصدير كشوف العمالة المعتمدة وتوليد قوالب واستيراد القيد المجمع إكسيل.

---

## 3. معايير الحوكمة الصارمة
- كل تدفق مستقل بذاته تماماً داخل مجلد `src/flows/<flow-code>-<slug>/`.
- يحتوي كل تدفق على 10 ملفات معيارية و 5 اختبارات متخصصة.
- يُحظر تماماً وجود أي استيراد بين تدفق وتدفق آخر داخل الموديول (Zero Cross-Flow Imports).
