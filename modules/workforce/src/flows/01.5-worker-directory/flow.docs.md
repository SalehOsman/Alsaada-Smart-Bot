# وثيقة اعتماد التدفق: [01.5] دليل وسجل العاملين الشامل والأرشيف السابق (360°)
## Flow Dossier: [01.5] Comprehensive Worker Directory & 360 Profile Hub

### 1️⃣ البطاقة التعريفية والمواصفات
* **كود التدفق:** `01.5`
* **الموديول المسؤول:** `modules/workforce`
* **الحالة:** 🟢 معتمد وموثق 100%
* **الأدوار المصرح لها (RBAC):** `SUPER_ADMIN`, `GENERAL_ADMIN`, `FIELD_ADMIN`, `ACCOUNTANT`, `EXECUTIVE`
* **الأدوار المحجوبة:** `WORKER`, `SUPPLIER`, `GUEST`

---

### 2️⃣ مسارات الاستدعاء
* **مسار القائمة:** `👥 الموارد البشرية` ⬅️ `📁 شؤون العاملين والتعيينات` ⬅️ `📋 دليل وسجل العاملين (360°)`
* **Callback Query:** `action:worker:directory`

---

### 3️⃣ خطوات الاستعراض والتحكم الميداني
1. **عرض الدليل التفاعلي:** عرض العاملين (10 في الصفحة) باستخدام مكون `WorkerPicker` المعتمد مع إظهار اسم الشهرة حصراً.
2. **عزل النطاق الجغرافي (Site Scoping):** حصر العرض تلقائياً على موقع المشرف الميداني، بينما يرى السوبر أدمن كافة المواقع.
3. **محرك البحث الذكي:** البحث المباشر بالاسم، الشهرة، الكود الوظيفي، أو الكود القديم.
4. **بطاقة العامل الشاملة (360°):** عرض كافة تفاصيل العامل (الهوية، الوظيفة، الموقع، التواريخ، الرخص، الموقف التأميني، التجنيد، هاتف الطوارئ، والحالة).
5. **الحجب المالي الصارم (RBAC Financial Masking):** حجب اليومية والراتب عن المشرفين الميدانيين وإظهاره حصراً للمدير العام والمحاسب.
6. **إجراءات التواصل والإدارة:** زر المراسلة المباشرة عبر واتساب، وزر طلب تعديل بيانات العامل.

---

### 4️⃣ حدود الأداء المعتمدة (SLA)
* **استجابة التقليب والصفحات:** أقل من 700ms (الفعلي المقاس < 70ms).
* **تحميل بطاقة الملف الشاملة:** أقل من 1200ms.
