### 4️⃣ خطوات الاستعراض والتحكم الميداني
1. **عرض الدليل التفاعلي:** عرض العاملين (10 في الصفحة) باستخدام مكون `WorkerPicker` المعتمد مع إظهار **اسم الشهرة حصراً**.
2. **عزل النطاق الجغرافي (Site Scoping):** حصر العرض تلقائياً على موقع المشرف الميداني، بينما يرى السوبر أدمن كافة المواقع.
3. **محرك البحث الذكي:** البحث المباشر بالاسم، الشهرة، الكود الوظيفي، أو الكود القديم.
4. **بطاقة العامل الشاملة (360°):** عرض كافة تفاصيل العامل (الهوية، الوظيفة، الموقع، التواريخ، الرخص، الموقف التأميني، التجنيد، هاتف الطوارئ، والحالة).
5. **الحجب المالي الصارم (RBAC Financial Masking):** حجب اليومية والراتب بنسبة 100% عن المشرفين الميدانيين وإظهاره حصراً للمدير العام والمحاسب.
6. **إجراءات التواصل والإدارة:** زر المراسلة المباشرة عبر واتساب، زر الاتصال الهاتفي المباشر (vCard)، وزر طلب تعديل بيانات العامل.
7. **فحص اكتمال الملف والبيانات:** تقييم آلي لحظي لنسبة اكتمال ملف العامل ومرفقاته وعرض قائمة النواقص بدقة مع إمكانية إرسالها للعامل عبر واتساب بنقرة واحدة.
