# 01.4 - تصدير واستيراد كشوف العمالة المتقدم إكسيل RTL

## 1. بطاقة الوظيفة وميثاق التشغيل
- **كود الوظيفة:** `01.4`
- **الموديول التابع:** `@alsaada/workforce` (قطاع الموارد البشرية وشؤون العاملين)
- **الحالة:** `Implemented` (معتمد ومختبر بنسبة 100%)
- **الأدوار المصرح لها بالاستيراد وتنزيل القالب:** `SUPER_ADMIN` حصراً.
- **الأدوار المصرح لها بالتصدير العام:** `SUPER_ADMIN`, `GENERAL_ADMIN`, `FIELD_ADMIN`, `ACCOUNTANT`, `EXECUTIVE`.
- **الأدوار المحجوبة:** `WORKER`, `SUPPLIER`, `GUEST`.

---

## 2. قواعد العمل والنزاهة المؤسسية (Business Rules)
1. **حجب وإسقاط البيانات المالية (RBAC Financial Data Masking):**
   - عند قيام المدير العام (`SUPER_ADMIN`) بتصدير الكشف، يتضمن الملف 33 عموداً شاملاً الرواتب والبدلات والحسابات البنكية ومسحوبات الكانتين.
   - عند قيام أي دور إداري آخر (`GENERAL_ADMIN`, `FIELD_ADMIN`, `ACCOUNTANT`, `EXECUTIVE`) بتصدير الكشف، يتم حجب وحذف الأعمدة المالية بالكامل برمجياً ويحتوي الملف على 25 عموداً إدارياً وتشغيلياً فقط.
2. **التدقيق الصارم لأرقام الهوية:**
   - فحص الأرقام القومية المصرية (14 رقماً) والتحقق من سنة الميلاد والقرن والمحافظة والنوع.
   - التحقق من جواز السفر للعمالة الوافدة وإلزامية تاريخ الميلاد والنوع.
3. **النزاهة الذرية وعدم القيد الجزئي:**
   - في حال وجود خطأ في صف واحد بالملف، يتم إيقاف الاستيراد بالكامل ورفض المعاملة وتزويد المستخدم بتقرير أخطاء تفصيلي بالصفوف وأرقامها.
4. **المزامنة والـ Transactional Outbox:**
   - كل قيد لعامل ينتج حدث `OutboxEvent` ومعاملة `WorkerAuditLog` ضمن معاملة ذرية `$transaction`.

---

## 3. نقاط الدخول والـ Callbacks
- `action:worker:download_excel`: تنزيل القالب الرسمي مع دليل الأكواد.
- `action:worker:upload_excel`: طلب رفع ملف الإكسيل.
- `action:worker_export:start`: فتح قائمة خيارات التصدير.
- `action:worker_export:do:all`: تصدير الكشف الشامل.
- `action:worker_export:dept_menu`: فتح قائمة تصفية الأقسام.
- `action:worker_export:job_menu:*`: فتح قائمة تصفية المهن مع التصفح.
- `action:worker_export:gov_menu`: فتح قائمة تصفية المحافظات.

---

## 4. سيناريوهات الاختبار المعتمدة
- **Unit Tests (`flow.unit.spec.ts`):** التحقق من توليد القالب، ودليل الأكواد، وتطابق أعمدة الحجب المالي (33 عمود للسوبر أدمن مقابل 25 لغيره).
- **Integration Tests (`flow.integration.spec.ts`):** اختبار الاستيراد الذري، إنشاء العمال، وأحداث الـ Outbox.
- **UX Tests (`flow.ux.spec.ts`):** اختبار التحديث الموضعي للرسالة واللوحات الختامية الرباعية الموحدة.
- **RBAC Tests (`flow.rbac.spec.ts`):** اختبار رفض وصول الأدوار غير المصرح لها (GUEST, WORKER, SUPPLIER).
- **Data Tests (`flow.data.spec.ts`):** اختبار تطابق صيغ التواريخ، ودعم الخطوط والألوان، وتكامل RTL.
