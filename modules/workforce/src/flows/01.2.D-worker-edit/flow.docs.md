# وثيقة اعتماد التدفق: [01.2.D] تعديل وتحديث بيانات عامل وحوكمة الموافقات
## Flow Dossier: [01.2.D] Worker Profile & Compensation Update Wizard

### 1️⃣ البطاقة التعريفية والمواصفات
* **كود التدفق:** `01.2.D`
* **الموديول المسؤول:** `modules/workforce`
* **الحالة:** 🟢 معتمد وموثق 100%
* **الأدوار المصرح لها (RBAC):** `SUPER_ADMIN`, `GENERAL_ADMIN`, `FIELD_ADMIN`, `ACCOUNTANT`, `EXECUTIVE`
* **الأدوار المحجوبة:** `WORKER`, `SUPPLIER`, `GUEST`

---

### 2️⃣ مسارات الاستدعاء
* **مسار القائمة:** `👥 الموارد البشرية` ⬅️ `📁 شؤون العاملين والتعيينات` ⬅️ `✏️ تعديل بيانات عامل`
* **Callback Query:** `action:worker_edit:pick`

---

### 3️⃣ خطوات التحكم الميداني والحوكمة المزدوجة
1. **اختيار العامل:** اختيار العامل من القائمة أو الدليل الشامل.
2. **اختيار الحقل المطلوب تعديله:** (الاسم، الشهرة، الهاتف، الطوارئ، المحفظة، العنوان، الرخصة، الموقف التجنيدي، انتهاء البطاقة).
3. **إدخال القيمة الجديدة:** إدخال القيمة مع الحذف الصامت الفوري للمدخلات النصية والتحقق الصارم من الصحة.
4. **المسار المزدوج للحوكمة:**
   - **المدير العام (SUPER_ADMIN):** تنفيذ وتطبيق فوري مباشر مع قيد التدقيق وتحديث الكاش.
   - **مشرف الموقع الميداني (FIELD_ADMIN):** إنشاء تذكرة طلب تعديل رسمية (`EDT-YYMMDD-XXX`) مع إرسالها لمركز موافقات السوبر أدمن.
5. **شاشة مراجعة واعتماد الطلبات:** للسوبر أدمن للبت في الطلبات بالموافقة والتطبيق اللحظي أو الرفض مع بيان السبب.

---

### 4️⃣ حدود الأداء المعتمدة (SLA)
* **استجابة الأزرار والخيارات:** أقل من 700ms.
* **التطبيق الفوري وقيد التدقيق:** أقل من 1200ms (الفعلي المقاس < 95ms).
