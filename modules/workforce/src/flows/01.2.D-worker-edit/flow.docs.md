### 4️⃣ خطوات التحكم الميداني والحوكمة المزدوجة
1. **اختيار العامل:** اختيار العامل من القائمة التفاعلية أو البحث بالكود والاسم.
2. **عرض بطاقة التبويبات:**
   - للسوبر أدمن: (👤 الشخصية | 💼 الوظيفية | 💰 المالية | 📑 المستندات).
   - للمشرف الميداني: (👤 الشخصية | 💼 الوظيفية | 📑 المستندات) مع حجب تبويب `💰 المالية` بالكامل.
3. **إدخال التعديل:**
   - للحقول النصية: حذف رسالة المستخدم فوراً وتعديل رسالة المطالبة موضعياً (`editMessageText`) عبر `promptMsgId` لمنع تراكم الرسائل في المحادثة.
   - لقوائم الاختيار (الجنسية، النوع، الرخص، الموقف التجنيدي): اختيار مباشر عبر الأزرار التفاعلية.
4. **مسار الحوكمة الإلزامي:**
   - **السوبر أدمن:** تطبيق مباشر في قاعدة البيانات (`applyDirectEdit`) مع تسجيل سجل تدقيق فوري.
   - **المشرف الميداني:** إنشاء تذكرة `WorkerEditRequest` بالحالة `PENDING` مع إشعار للمدير العام، وبقاء بيانات العامل كما هي دون أي مساس حتى اعتمادها.
5. **شاشة مراجعة واعتماد الطلبات:** شاشة مخصصة للمدير العام لاعتماد الطلب مع التطبيق اللحظي أو رفضه مع إبداء السبب.
