## 🧭 1. نظرة عامة ومسارات الوصول السريعة (Access Shortcuts)

يُعد **مركز إعدادات النظام (Settings Hub)** لوحة القيادة السيادية للمدير العام، حيث يتيح له التحكم في الهوية المؤسسية للشركة، مصفوفة الفروع والمشاريع، الملف الشخصي، فحص كفاءة السيرفر، وتجربة واجهات كافة أدوار المنظومة (Ghost Mode).

### 🚀 مسارات الوصول:
* **من القوائم الرئيسية:** أرسل `/start` ⬅️ اضغط **`[ ⚙️ إعدادات النظام ]`**.
* **الأوامر المباشرة السريعة:**
  * `/settings` أو `/admin`: فتح لوحة الإعدادات بالتصنيفات الثلاثة.
  * `/company` أو `/org`: فتح بطاقة بيانات وملف الشركة مباشرة.
  * `/sites` أو `/projects`: فتح مصفوفة المشاريع والفروع الميدانية مباشرة.
  * `/profile` أو `/me`: فتح الملف الشخصي للمدير العام وتعديل الاسم/الهاتف.
  * `/exit_ghost`: إنهاء وضع المحاكاة فورياً في أي وقت.
  * `/ping`: فحص كفاءة النظام واستجابة قاعدة البيانات.

## 🗂️ 2. خارطة الأبواب والتصنيفات الفرعية الثلاثة

لضمان سهولة الاستخدام ومنع تكدس الأزرار على شاشات الهواتف، تم تقسيم الإعدادات إلى 3 أقسام رئيسية متناسقة:

```
[ ⚙️ مركز إعدادات النظام ]
 ├── 🏢 [ 🏢 الكيان المؤسسي والمشاريع ]
 │    ├── [ 🏢 الملف التعريفي وبيانات الشركة ]  --> (استعراض وتعديل الحقول الـ 8)
 │    └── [ 🏗️ مصفوفة المشاريع والمواقع الميدانية ] --> (استعراض، تبديل، إضافة)
 │
 ├── 👤 [ 👤 الحساب والأمان والمحاكاة ]
 │    ├── [ 👤 ملفي الشخصي (حساب المدير العام) ] --> (الاسم الرسمي + الهاتف المشفر)
 │    └── [ 🎭 محاكاة وتقمص الأدوار Ghost Mode ] --> (محاكاة الأدوار الخمسة)
 │
 └── ⚡ [ ⚡ أداء وتشغيل المنظومة ]
      └── [ ⚡ فحص كفاءة واستجابة النظام /ping ] --> (فحص DB و Redis موضعياً)
```

## 🏢 3. الباب الأول: الكيان المؤسسي والمشاريع الميدانية

### أ. إدارة بيانات الشركة الرسمية (`Corporate Profile Manager - NEW-07`):
* **الغرض:** الحفاظ على بيانات الشركة المعتمدة في العقود، الترويسات، وقسائم الرواتب.
* **خطوات الاستخدام والتعديل:**
  1. ادخل إلى: `[ 🏢 الكيان المؤسسي والمشاريع ]` ⬅️ `[ 🏢 الملف التعريفي وبيانات الشركة ]`.
  2. استعرض البطاقة الحالية المسحوبة من PostgreSQL:
     * 🏛️ اسم الشركة القانوني
     * 🏷️ الاسم التجاري المختصر
     * 📜 رقم السجل التجاري
     * 💳 رقم البطاقة الضريبية
     * 📍 المقر الرئيسي والإداري
     * 📞 هاتف الإدارة والتواصل
     * ✉️ البريد الإلكتروني الرسمي
     * 💱 العملة الأساسية (`EGP`)
  3. لتعديل أي بيان: اضغط زر الحقل (مثل: `[ ✏️ الاسم التجاري ]`).
  4. اكتب القيمة الجديدة في الشات وأرسلها.
  5. يقوم النظام بحفظ القيمة في قاعدة البيانات، **حذف رسالتك تلقائياً**، وتحديث الشاشة في نفس الموضع (`In-Place`).

---

#### ب. مصفوفة المشاريع والفروع والمواقع الميدانية (`Sites & Projects Hub - NEW-08`):
* **الغرض:** التحكم في مقرات العمل، مناجم الفوسفات، ومواقع التشغيل الميدانية والمقر الرئيسي.
* **الهيكلية المحدثة لبطاقة الموقع وقائمة التعديل الموحدة:**
  1. ادخل إلى: `[ 🏢 الكيان المؤسسي والمشاريع ]` ⬅️ `[ 🏗️ مصفوفة المشاريع والمواقع الميدانية ]`.
  2. ستظهر قائمة بالمواقع المسجلة مع حالتها وعدد عمالتها (بما فيها المقر الرئيسي `STE-HQ` وموقع أبو طرطور `STE-01`).
  3. **بطاقة تفاصيل الموقع الميداني المنظمة:**
     * تعرض كافة البيانات التشغيلية والجغرافية بوضوح:
       - اسم الموقع، الكود الهيكلي، المشروع التابع له، المحافظة، إحداثيات GPS، رابط خرائط Google، نطاق السياج، والحالة التشغيلية.
     * الأزرار التنفيذية المباشرة:
       - **`[ ✏️ تعديل المعلومات ]`:** فتح القائمة الفرعية المخصصة للتعديل (دون تكدس الشاشة الرئيسية).
       - **`[ 🔴 تعطيل / 🟢 تنشيط ]`:** تبديل حالة الموقع تشغيلياً بضغطة زر موضعية.
       - **`[ 🔙 العودة لمصفوفة المواقع ]`** و **`[ 🏠 القائمة الرئيسية ]`**.
  4. **قائمة تعديل معلومات الموقع الميداني (`Site Edit Sub-Menu`):**
     * **`[ ✏️ تعديل اسم الموقع ]`:** إرسال الاسم الجديد نصياً وتحديثه موضعياً.
     * **`[ 🏢 تعديل المشروع التابع له ]`:** استعراض المشاريع القائمة كأزرار سريعة للاختيار المباشر، أو خيار `[ ➕ كتابة اسم مشروع جديد / مخصص ]` لربط الموقع بمشروع جديد تلقائياً.
     * **`[ 🗺️ تعديل المحافظة / الإقليم ]`:** إرسال اسم المحافظة وتحديثه موضعياً.
     * **`[ 📐 تعديل نطاق السياج الجغرافي ]`:** اختيار النطاق بالأزرار (`500م`, `1000م`, `2000م`, `5000م`) أو إرسال رقم مخصص بالأمتار.
     * **`[ 📍 تسجيل / تحديث GPS ]`:** إرسال الموقع مباشرة من تليجرام (`Send Location 📎`)، أو إرسال الإحداثيات كنص (`25.4412, 30.5512`)، أو رابط خرائط Google (بما في ذلك الروابط المختصرة `maps.app.goo.gl` عبر محلل التوجيه التلقائي).
     * **`[ ◀️ رجوع لبطاقة الموقع ]`:** للعودة السلسة بدون إلغاء أو خروج.
  5. **إضافة موقع جديد بالتوليد التسلسلي التلقائي (`Auto Sequential Code`):**
     * اضغط `[ ➕ إضافة موقع / فرع ميداني جديد ]`.
     * أرسل اسم الموقع نصياً.
     * يقوم النظام تلقائياً باحتساب الكود التسلسلي التالي وحجزه (مثال: `STE-02`) مع زر `[ ✅ اعتماد الكود المقترح ]` أو خيار كتابة كود مخصص.
     * اختر المحافظة من الأزرار السريعة أو أرسلها نصياً.
     * يتم حفظ الموقع فورياً في PostgreSQL وتنشيطه في المنظومة.
  6. **ميثاق معالجة الأخطاء والتنقل التفاعلي (Universal Error UX Standard):**
     * يُحظر ظهور أي رسالة خطأ أو تنبيه بدون أزرار تحكم تفاعلية (`Zero Orphan Error Messages`).
     * عند حدوث أي خطأ إدخال (مثل إرسال نص غير صالح، أو إحداثيات غير قابلة للاستخراج، أو رقم سياج غير صحيح)، تظهر رسالة التنبيه مرفقة دائماً بالأزرار التالية:
       - `[ 🔄 إعادة المحاولة ]` / `[ 🔄 إعادة إدخال القيمة ]`.
       - `[ ◀️ رجوع لقائمة التعديل ]` / `[ 🔙 العودة لبطاقة الموقع ]`.
       - `[ 🏠 القائمة الرئيسية ]`.

## 👤 4. الباب الثاني: الحساب والأمان والمحاكاة

### أ. ملف المدير العام الشخصي (`Super Admin Profile - NEW-09`):
* **الغرض:** تحديث الاسم الرسمي ورقم الهاتف المشفر للمدير العام.
* **خطوات الاستخدام:**
  1. ادخل إلى: `[ 👤 الحساب والأمان والمحاكاة ]` ⬅️ `[ 👤 ملفي الشخصي (حساب المدير العام) ]`.
  2. ستظهر بطاقة الهوية الإدارية الرسمية.
  3. **لتعديل الاسم الرسمي:** اضغط `[ ✏️ تعديل الاسم الرسمي ]` ⬅️ اكتب اسمك الثلاثي/الرباعي في الشات.
  4. **لتسجيل أو تعديل رقم الهاتف:** اضغط `[ 📱 تسجيل / تعديل رقم الهاتف ]` ⬅️ اكتب رقم هاتفك (مثال: `01012345678` أو `+201012345678`):
     * يقوم النظام بتشفير الرقم فورياً بخوارزمية التشفير البنكي **AES-256-GCM**.
     * يتم توليد الفهرس الأعمى (**HMAC-SHA256 Blind Index**) لتمكين البحث المالي دون كشف الرقم الحقيقي.
     * تُحذف رسالتك النصية بصمت لمنع ظهور رقمك في سجل المحادثة.

---

### ب. تعيين وتوزيع مدراء المواقع والفروع (`Admin Site Scoping - NEW-10`):
* **الغرض:** حصر صلاحيات المشرفين ومدراء المواقع جغرافياً وتشغيلياً في حدود موقع محدد (أو المقر الرئيسي).
* **محرك العزل البرمجي (RBAC Scoping Engine):**
  - **أدمن موقع معين (مثل موقع الخارجة):** تُحصر كافة شاشاته وعملياته في موقعه فقط؛ فلا يشاهد إلا عمال موقعه، ولا يدير إلا عهد وموردين ومصروفات موقعه.
  - **أدمن المقر الرئيسي (`STE-HQ`):** تنحصر صلاحياته في عمالة الإدارة العامة، عهد المكتب، ومصروفات وبوفيه المقر الرئيسي.
  - **السوبر أدمن والجينرال أدمن:** يتمتع بصلاحية شمولية لكافة المواقع (`Global Access`).
* **خطوات التعيين:**
  1. ادخل إلى: `[ 👤 الحساب والأمان والمحاكاة ]` ⬅️ `[ 👥 تعيين وتوزيع مدراء المواقع ]`.
  2. استعرض قائمة المستخدمين ونطاق إشراف كل منهم.
  3. اضغط على اسم المستخدم، ثم اختر الموقع المطلوب حصره عليه من الأزرار (أو امنحه `🌐 وصول عام وشامل`).

---

### ج. محرك محاكاة وتقمص الأدوار (`Ghost Mode Engine - NEW-06`):
* **الغرض:** تمكين المدير العام من معايشة تجربة واجهة أي دور ميداني بنفسه (مشرف، عامل، مورد، زائر، تنفيذي) للتأكد من انضباط الصلاحيات وسلاسة العمليات الميدانية.
* **الأدوار المتاحة للمحاكاة:**
  1. `👔 الإدارة التنفيذية والمالية (EXECUTIVE)`
  2. `🛡️ المشرف الميداني (FIELD_ADMIN)`
  3. `👷 العامل الميداني (WORKER)`
  4. `🚚 المورد ومقاول الباطن (SUPPLIER)`
  5. `👤 الزائر والمستخدم الجديد (GUEST)`
* **ضمانة الهروب السيادي الحتمي (Sovereign Escape Hatch):**
  - عند تقمص أي دور، يظهر دائماً أسفل كل شاشة زر بارز:  
    `[ 🎭 إنهاء وضع المحاكاة (العودة كمدير عام) ]`.
  - في حال ضياع الرسالة، يكفي إرسال الأمر المباشر `/exit_ghost` للعودة الفورية.
  - لا تتأثر صلاحيات السوبر أدمن الحقيقية في قاعدة البيانات مطلقاً؛ فالجلسة مدارة بالكامل داخل كاش Redis.

## ⚡ 5. الباب الثالث: أداء وتشغيل المنظومة (APM & Health)

* **الغرض:** التحقق اللحظي من سرعة استجابة الخادم ومحركات البيانات.
* **المؤشرات المعروضة عند الضغط على `[ ⚡ فحص كفاءة واستجابة النظام /ping ]`:**
  * 🗄️ **قاعدة بيانات PostgreSQL:** حالة الاتصال وزمن الاستعلام بالمللي ثانية (مثال: `4ms`).
  * ⏱️ **استجابة المحرك المركزي:** إجمالي زمن دورة المعالجة (مثال: `12ms`).
  * 💾 **استهلاك الذاكرة (RAM Heap):** استهلاك الذاكرة بالحجم الفعلي (MB).
  * ⏳ **مدة التشغيل الميداني (Uptime):** الثواني والدقائق منذ آخر تشغيل للحاوية.
  * 🛡️ **الحاوية:** `alsaada_enterprise_bot`.
* **ميزة إعادة الفحص الموضعي:** زر `[ 🔄 إعادة الفحص ]` يعيد القياس في نفس الرسالة دون تراكم الشات.

## 🛡️ 6. معايير الأمان والجودة الهندسية المطبقة

1. **الحجب المسبق للواجهات (Strict Pre-Render RBAC Masking):**  
   لا يظهر زر `[ ⚙️ إعدادات النظام ]` أو أي من وظائفه لأي مستخدم آخر في المنظومة (عامل، مشرف، مورد، زائر)، ويتم التحقق برمجياً قبل تصيير لوحة المفاتيح.
2. **الحذف الصامت للمدخلات (Silent Clean Input):**  
   أي قيمة نصية يرسلها المدير العام لتعديل حقل يتم حذفها فور معالجتها بنجاح للحفاظ على نظافة المحادثة وعدم تسريب أرقام الهواتف أو البيانات الحساسة.
3. **انعدام الطرق المسدودة (Zero Dead Ends):**  
   تحتوي كل شاشة فرعية دون استثناء على زرين إلزاميين:
   * `[ 🔙 العودة للقسم السابق ]`
   * `[ 🏠 القائمة الرئيسية ]` (`action:main_menu`)
