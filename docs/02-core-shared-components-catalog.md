# 🧱 كتالوج المكونات المشتركة المجهزة مسبقاً
## Core Reusable Components & UI Building Blocks Catalog

> [!IMPORTANT]
> **دستور النواة المشتركة (Core Kernel Contract):**
> تُمثل هذه المكونات البنية الأساسية لكافة تدفقات المنظومة. لا يُسمح لأي موديول أن يعيد بناء شاشات اختيار العمال، أو حسابات المبالغ، أو بطاقات الإنجاز. جميعها تُستدعى كدوال برمجية موحدة تضمن 100% تطابق في تجربة المستخدم وتمنع الأخطاء البشرية.

### 1️⃣ محرك اختيار العمال (`UniversalWorkerPicker`)

* **المسؤولية الوظيفية:**
  - عرض قائمة العمال مع التصفية بالمهنة أو موقع العمل.
  - دعم الاختيار الفردي (`SingleSelect`) والاختيار المجمع لعدة عمال (`MultiSelect`).
  - محرك بحث نصي فوري بالاسم أو كود العامل (مع الحذف الصامت لرسائل البحث لمنع تراكم المحادثة).
  - خيار الضيافة الميدانية المعتمدة (`Hospitality Action`) عند تخصيص الصرف للموقع وليس لعامل بعينه.
  - ترقيم الصفحات الموضعي السلس (`In-Place Pagination`).

* **شكل الاستدعاء البرمجي:**
  ```typescript
  const selection = await promptWorkerSelection(conversation, ctx, {
    title: '👥 اختر العامل المستلم للمسحوبات:',
    allowMultiSelect: false,
    allowSearch: true,
    customActionButtons: [
      { text: '☕ تسجيل لضيافة الموقع', callbackData: 'hospitality' }
    ],
  });
  if (selection.status === 'CANCELLED') return;
  const worker = selection.workers[0];
  ```

### 2️⃣ محرك المبالغ والمدخلات المالية (`UniversalAmountPicker`)

* **المسؤولية الوظيفية:**
  - لوحة فئات نقدية سريعة قابلة للتخصيص (`100`, `200`, `500`, `1000`, `2000` ج.م).
  - استقبال الإدخال اليدوي مع تحويل الأرقام المشرقية (`١٥٠٠` ➡️ `1500`) وإزالة فواصل الآلاف ورموز العملات.
  - فحص حدود ومصادقات الأمان المالي (`validateAmount`):
    * منع المبالغ الصفرية أو السالبة.
    * التحقق من سقف الصرف المسموح به للعامل أو العهدة.
  - فحص رادار مخاطر التكرار المالي (`DuplicatePaymentRisk`): تنبيه المشرف إذا كان العامل قد حصل على سلفة مماثلة خلال آخر 24 ساعة لطلب تأكيد إضافي قبل الصرف.

---

### 3️⃣ محرك الكميات ووحدات القياس (`UniversalQuantityPicker`)

* **المسؤولية الوظيفية:**
  - أزرار سريعة للكميات الشائعة (`1`, `2`, `3`, `5`, `10 خرطوشة / كرتونة`).
  - دعم وحدة القياس المخصصة حسب الصنف (علبة، كرتونة، وجبة، لتر، طن).
  - فحص نوع الوحدة: منع الكسور العشرية للأصناف غير القابلة للتجزئة (مثل السجائر أو وجبات الإعاشة)، والسماح بها للأوزان والأحجام (الفوسفات والسولار).

---

### 4️⃣ محرك التواريخ والفترات الميدانية (`UniversalDatePicker`)

* **المسؤولية الوظيفية:**
  - أزرار الفترات السريعة (اليوم، أمس، أول الشهر، نهاية الشهر).
  - تقويم تفاعلي مدمج في الرسالة (`Inline Calendar Picker`).
  - حساب فارق الأيام تلقائياً (في الإجازات والمأموريات ومعدلات استهلاك المحروقات).
  - حواجز الأمان: منع اختيار تواريخ انتهاء قبل تاريخ البدء، ومنع تواريخ في المستقبل لمصروفات سابقة.

---

### 5️⃣ بطاقة المراجعة والاعتماد المالي الموحدة (`UniversalConfirmationCard`)

* **المسؤولية الوظيفية:**
  - عرض بطاقة مراجعة نهائية موحدة قبل الحفظ تشمل:
    * تفاصيل المعاملة (الصنف/البيان، الكمية، السعر، الإجمالي).
    * اسم وكود العامل مع ملخص مسحوبات الشهر الحالي (سلف نقدية + سجائر).
    * اسم المشرف المسجل والتوقيت الميداني الدقيق.
  - **قفل التزامن الموزع (`Redis Mutex Lock`):** تأمين زر التأكيد ضد الضغط المزدوج أو بطء شبكة المحمول لمنع تسجيل القيد مرتين.

---

### 6️⃣ لوحة أزرار ما بعد الإنجاز الموحدة (`UniversalCompletionCard`)

* **المسؤولية الوظيفية:**
  - التطبيق الإلزامي الصارم للبند 5.2 من دستور العمل، حيث تترتب الأزرار الختامية بالترتيب التالي:
    1. **📲 إرسال إيصال السند للعامل عبر واتساب:** رابط مباشر يحتوي نص إيصال الصرف الرسمي ورقم السند ورابط الاعتراض.
    2. **➕ تكرار نفس العملية فوراً:** مثل (`[ ➕ تسجيل سلفة أخرى ]`) لبدء معاملة جديدة بضغطة واحدة دون فتح القوائم.
    3. **🔙 العودة لقسم الوظيفة:** الرجوع للقائمة الفرعية للقسم التابع له الإجراء.
    4. **🏠 القائمة الرئيسية:** (`[ 🏠 القائمة الرئيسية ]`) لمنع وصول المستخدم لأي طريق مسدود.

---

### 7️⃣ محرك توثيق المرفقات والصور (`UniversalPhotoAttachment`)

* **المسؤولية الوظيفية:**
  - استقبال صور فواتير المشتريات، إيصالات التحويل البنكي، أو بوالص الشحن.
  - ضغط الصورة تلقائياً لتقليل استهلاك مساحة التخزين.
  - رفع الصورة إلى المجلد المخصص على Google Drive أو خادم التخزين السحابي.
  - ربط رابط الصورة الرسمي بصف السند في شيت الحركات برقم السند المعتمد.

---

### 8️⃣ موجه الإشعارات والتوبيكات الذكي (`MultiChannelDispatcher`)

* **المسؤولية الوظيفية:**
  - فك شفرة المعاملة وتوجيه إشعار الجروب الفائق تلقائياً إلى الـ **Forum Topic** المخصص بناءً على المعرف الرقمي:
    * `🚬 المسحوبات والضيافة`
    * `🚚 النقل واللوجستيات`
    * `⛽ المحروقات والمخازن`
    * `💵 العهد النقدية والمصاريف`
    * `👥 الشؤون الإدارية والقرارات`
    * `💡 الإرشادات والتوجيهات العامة` (التوبيك العام)
  - إرسال إشعار تليجرام الفوري لحساب العامل الشخصي إن كان مربوطاً بالبوت.
  - توثيق سجلات الرقابة الميدانية في شيتات المتابعة والـ APM.

### 9️⃣ حزمة محولات وتنسيقات تليجرام الرسمية والنواة المشتركة (`Universal Telegram Native Formatters & UX Hooks`)

* **المسار البرمجي:** `packages/core-components/src/formatting/telegram-formatters.ts`
* **المسؤولية الوظيفية:**
  - توفير مكتبة أدوات معيارية موحدة لكافة موديولات المنظومة لضمان تجربة مستخدم ميدانية احترافية بدون تكرار الكود:
    1. **مسار التتبع الموحد (`formatBreadcrumbs`):**
       - صياغة شريط التنقل الهرمي الموحد بفاصل الزاوية (` ❯ `) مثل:
         `formatBreadcrumbs(['⚙️ الإعدادات', '🏢 الكيان المؤسسي والمشاريع', '👥 تعيين المشرفين'])`
    2. **النسخ بنقرة واحدة عبر المونوسبيس (`formatClickToCopy`):**
       - تغليف المعرفات الرقمية وأكواد التتبع والتوكنات بوسم `<code>` لتفعيل النسخ المباشر بنقرة إصبع واحدة.
    3. **التعتيم التفاعلي على البيانات الحساسة (`formatSpoiler`):**
       - تغليف الأرقام القومية والمبالغ بالوسم المعتمد `<tg-spoiler>` لكشفها بنقرة مستخدم ومنع استراق النظر.
    4. **الاقتباسات المطوية القابلة للتوسيع (`formatExpandableQuote`):**
       - اختصار التقارير وتتبع الأخطاء وسجلات الأحداث عبر `<blockquote expandable>` لمنع تشويه الشاشات.
    5. **نوافذ التنبيه المنبثقة الرسمية (`showModalAlert` & `buildModalAlertOptions`):**
       - إظهار حوارات التحذير والإخطار المباشرة (`show_alert: true`) عند الحجب أو رفض الصلاحيات.
    6. **كبح معاينات الروابط المشوهة (`DISABLED_LINK_PREVIEWS` & `buildLinkPreviewOptions`):**
       - كبح معاينات روابط خرائط جوجل وروابط واتساب التلقائية لمنع تشويه المحادثات.
    7. **مؤشرات المعالجة التفاعلية والنشاط الحي (`withChatAction` & `sendChatActionSafe`):**
       - تجديد مؤشرات المعالجة (`typing`, `upload_document`) تلقائياً كل 4.5 ثوانٍ لطمأنة المستخدم أثناء العمليات الطويلة.
