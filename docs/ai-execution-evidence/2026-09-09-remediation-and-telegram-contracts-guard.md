# توثيق الحوكمة: إصلاحات بطاقة العامل الشاملة وحارس عقود تليجرام الآلي

- التاريخ: 2026-09-09
- الحالة: معتمد وموافق عليه رسمياً
- عبارة الاعتماد الإلزامية: موافق على التعديل او الايقاف او الحذف

## نطاق الأعمال المنفذة
1. إصلاح عطل فتح بطاقة العامل الشاملة (360 Card) الناتج عن تجاوز حد تليجرام لبايتات الرابط (512 بايت) بتحويل طلب النواقص إلى شاشة مخصصة متوافقة تماماً وبشكل كامل.
2. تمكين كشف وتمويه الرقم القومي للأدمن والسوبر أدمن تفاعلياً موضعياً (ID Toggle).
3. توفير اتصال هاتفي مباشر ومراسلة واتساب آمنة.
4. تثبيت كيبورد التنقل السفلي الدائم ومنع حذفه عند التنقل بين الشاشات.
5. استئصال الأكواد الميتة والمكررة في bot-server وتحويل الخدمات إلى واجهات خفيفة تفوض لموديول workforce.
6. استحداث أداة حوكمة آلية tools/governance/verify-telegram-contracts.ts لمنع تكرار تجاوزات حدود Telegram Bot API مستقبلاً.
7. تحديث الفهرس المعماري وأوامر الجودة والحوكمة في README.md ومطابقة سجل الترحيل Master Migration Registry في docs/19 بتسجيل NEW-12 و NEW-13 و NEW-14 وتحديث تدفقات workforce لرفع نسبة محور التوثيق إلى 100%.
