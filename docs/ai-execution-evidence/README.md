# AI Execution Evidence Register

هذا المجلد مخصص لتقارير إثبات تنفيذ أدوات الذكاء الاصطناعي.

لا يُقبل إعلان أي مهمة بأنها مكتملة أو `PASS` دون تقرير مستقل داخل هذا المجلد يحتوي على:

1. نطاق المهمة.
2. الملفات المقروءة.
3. الملفات المعدلة.
4. سبب كل تعديل.
5. أوامر التحقق ونتائجها.
6. جدول بوابات G1 إلى G10.
7. المخاطر والتحفظات المتبقية.
8. القرار النهائي.

أي تقرير يخلو من الأدلة أو يستخدم عبارات نجاح عامة دون نتائج تحقق رقمية يعتبر `INVALID_REPORT`.
