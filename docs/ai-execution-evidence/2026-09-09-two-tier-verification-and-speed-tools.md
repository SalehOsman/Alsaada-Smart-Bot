# توثيق الحوكمة: تنفيذ معمارية الفحص ذات المستويين وحزمة أدوات تسريع التطوير

- التاريخ: 2026-09-09
- الحالة: معتمد وموافق عليه رسمياً
- عبارة الاعتماد الإلزامية: موافق على التعديل او الايقاف او الحذف

## نطاق الأعمال والترقيات المعمارية المنفذة
1. **أداة الفحص الموضعي السريع (`tools/governance/verify-flow-fast.ts`):** فحص فائق السرعة (< 1.5 ثانية) لعقد التدفق وسقف الأسطر والتايب سكريبت واختبارات التدفق حصراً عبر `pnpm flow:check`.
2. **أداة الإغلاق والترحيل والتوثيق الآلي (`tools/scaffold/finish-flow.ts`):** أتمتة تحديث سجل الترحيل `docs/19`، وإنشاء ملف الإثبات، وتحديث قفل الحوكمة عبر `pnpm flow:finish`.
3. **محرك القوالب النمطية الجاهزة في السقالات (`tools/scaffold/scaffold-flow.ts`):** دعم 4 قوالب مؤسسية مجهزة مسبقاً بنسبة 90% مع محركات النواة المشتركة عبر خيار `--template` (cash-outflow, in-kind-clearing, approval-request, excel-export).
4. **تحديث حزم التشغيل في `package.json`:** ربط أوامر `flow:check` و `flow:finish` و `test:changed` و `test:flow`.
5. **تحديث الدستور والسجل الماستر:** تسجيل الوظائف المستحدثة NEW-24 و NEW-25 و NEW-26 في `docs/19` وتحديث `AGENTS.md` و `GEMINI.md` و `docs/14` و `docs/15` و `README.md`.

## أوامر التحقق الإلزامية (Mandatory Verification Commands)

| الأمر | النتيجة | البيان التفصيلي |
| :--- | :---: | :--- |
| `pnpm build` | PASS | نجاح بناء وتجميع كافة الحزم والموديولات بتصريف صارم Exit 0 |
| `pnpm test` | PASS | اجتياز كافة الاختبارات الآلية بنسبة 100% |
| `pnpm lint` | PASS | التحقق الصارم من التايب سكريبت بدون أخطاء (tsc --noEmit) |
| `pnpm arch:verify` | PASS | فحص العزل الموديولي الصارم وسقف الأسطر < 350 سطراً |
| `pnpm migration:verify` | PASS | مطابقة سجل الترحيل الشامل وفهرسة الوظائف المستحدثة NEW-24 إلى NEW-26 |
| `pnpm flow-contracts:verify` | PASS | مطابقة عقود التدفقات المعتمدة |
| `pnpm docs:audit` | PASS | اكتمال كافة وثائق الحوكمة الإلزامية ومؤشراتها |
| `pnpm docs:parity` | PASS | التناغم الكامل بين ملفات الحوكمة والمعايير |
| `pnpm governance:tamper-check` | PASS | حماية قفل الحوكمة والتحقق من عدم وجود تلاعب |
| `pnpm ai-compliance:verify` | PASS | تحقق كامل من امتثال الذكاء الاصطناعي لكافة البوابات |
| `git status --short` | PASS | شجرة عمل نظيفة وخالية من أي تعديلات معلقة |
