# توثيق الحوكمة: تنفيذ حزمة المحركات المشتركة المؤسسية وأدوات السقالات وخطافات Git

- التاريخ: 2026-09-09
- الحالة: معتمد وموافق عليه رسمياً
- عبارة الاعتماد الإلزامية: موافق على التعديل او الايقاف او الحذف

## نطاق الأعمال والترقيات المعمارية المنفذة
1. **أداة توليد التدفقات الآلية (`tools/scaffold/scaffold-flow.ts`):** توليد تلقائي لكافة ملفات الشريحة الرأسية الـ 15 المعتمدة في الوثيقة 21 مع قوالب الاختبارات الأربعة بنقرة واحدة عبر أمر `pnpm make:flow`.
2. **خطافات Git للتحقق الفوري المسبق (`.githooks/pre-commit`):** تفعيل فحص التايب سكريبت وعقود تليجرام وسقف الأسطر المعماري تلقائياً قبل كل commit.
3. **محرك المقاصة المالية الثلاثية المغلقة (`TripleBalanceClearingEngine`):** فصل مسحوبات السجائر، مشتريات الموردين، والسلف النقدية وفق القاعدة 2.6.3.
4. **صمام فحص وقفل رصيد العهدة (`UniversalCustodyGate`):** فحص ذري لمنع الأرصدة السالبة والصرف المتزامن المزدوج.
5. **محرك الجدولة والأقساط وسقف الخصم الآمن (`UniversalInstallmentEngine`):** جدولة الأقساط وقفل كسور القروش في القسط الأول وفحص سقف الخصم من الراتب.
6. **مسار تخزين وحفظ المستندات والإيصالات الهرمي (`UniversalAttachmentPipeline`):** حفظ منظم بمسارات هرمية وبصمة SHA-256 جنائية.
7. **محرك دورات الاعتماد الهرمية (`UniversalApprovalWorkflow`):** إدارة بطاقات الاعتماد والموافقة والرفض المسبب وسجل التدقيق.
8. **محرك رصيد الإجازات التناسبي والورديات (`UniversalShiftAccrualEngine`):** حساب استحقاق الإجازات اللحظي وفق الورديات المتغيرة (20+10, 24+6, 26+4, 6+1).
9. **طابور المزامنة الذري لـ Google Sheets في الخلفية (`TransactionalOutboxQueue`):** ضمان سرعة استجابة البوت (< 15ms) وترحيل العمليات في الخلفية مع إعادة المحاولة التلقائية.
10. **إلزامية الحوكمة للـ AI Agents:** تثبيت نصوص إلزامية صريحة في `AGENTS.md` و `GEMINI.md` و `docs/14` تلزم باستخدام هذه الأدوات والمحركات وتمنع إعادة كتابتها يدوياً.
11. **سجل الترحيل الماستر (`docs/19`):** تسجيل الأدوات كـ Novel Features برقم NEW-15 إلى NEW-23.
