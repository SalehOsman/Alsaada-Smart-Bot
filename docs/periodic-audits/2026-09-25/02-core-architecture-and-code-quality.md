# المحور 02: معمارية النواة وجودة الكود
## 1. الدرجة والوزن
الوزن 10؛ فحص ساكن.

## 2. الخلاصة والتغطية
الـ monorepo مقسم إلى apps/packages/modules، لكن bot-server/src/bot.ts (677 سطرًا) يجمع تسجيلًا عامًا ووظائف مؤسسة. روجعت bot.ts وindex.ts وmodules.registry.ts وعقود core-components.

## 3. التقييم
| الجانب | الحالة |
|---|---|
| تقسيم المستودع | واضح |
| تسجيل الوظائف | مركزي ومختلط |
| عقود runtime | مرتبطة بـPrisma/Redis وبها any |
| قالب عام | يحتاج فصلًا |

## 4. النتائج
**2.1 وظائف أعمال في النواة:** bot.ts يسجل قسيمة راتب وكشف حساب وفواتير مورد وتسجيل منسوب وcallbacks للعاملين. حذف الوحدة وحده لن يعزلها.

**2.2 عقد runtime فضفاض:** ModuleRuntimeContext يمرر Prisma وRedis وAPI ويقبل any ومفاتيح عامة؛ يحد ذلك من تبديل الخدمات.

**2.3 خريطة README ناقصة:** لا تعرض apps/admin-dashboard وapps/docs وعدة حزم ووحدة sandbox.

## 5. التوصيات والمخاطر
اجعل التطبيق لدورة الحياة والmiddlewares والتوجيه، وانقل وظائف المجال إلى الوحدات، ثم قوّ عقود runtime. لم أشغل lint/typecheck.
