# المحور 08: لوحة الإدارة وواجهة المستخدم
## 1. الدرجة والوزن
الوزن 4؛ مراجعة ساكنة محدودة دون تصفح.

## 2. الخلاصة
لوحة Next.js مستقلة، بها opaque sessions وDB validation وRBAC. وظائفها تشمل workforce والمالية واللوجستيات.

## 3. النتائج
**8.1 اللوحة مرتبطة بالمنتج الحالي:** ليست واجهة محايدة لقالب بوت، وتحتاج أن تكون اختيارية أو يعاد فصلها عند إنشاء Tembot.

**8.2 tenant scope غير محسوم:** جلسة المستخدم تحمل role/site في الكود المقروء؛ لم أراجع كل API لإثبات عزلها.

## 4. التوصيات والمخاطر
تتبع tenant scope لكل API وحدد إن كانت اللوحة جزءًا من Tembot. لم تُراجع جميع endpoints أو UX بصريًا.
