# 📋 خطة العمل رقم 31: مطابقة القائمة الجانبية بالداشبورد مع البوت والشاشة الشاملة لتسجيل وتعيين العامل الجديد (مع تحسينات UX)
## Master Plan 31: Dashboard Nested Sidebar Parity, Dynamic Lookups & Comprehensive Worker Onboarding with Advanced UX

> [!IMPORTANT]
> **ميثاق الحوكمة ومقررات جلسة العصف الذهني المحدثة (`/grill-me` UX Protocols):**
> 1. **القائمة الجانبية الشجرية (Nested Accordion):** مطابقة كاملة للأقسام الـ 5 لقطاع «الموارد البشرية والعمالة»، مزودة بـ:
>    - فلتر بحث سريع داخل القائمة (Quick Menu Filter).
>    - عدادات وشارات حية (Live Badges).
>    - مسار تنقل بصري هرمي (Hierarchical Visual Trail).
> 2. **استئصال النصوص الثابتة (Dynamic DB Lookups):** جلب المواقع والوظائف ومخزن السجائر والسكن ديناميكياً من قاعدة البيانات عبر خادم `Server Component / Server Action`.
> 3. **التحكم بجميع حقول العامل (30+ حقل):** إدخال وإدارة كافة الحقول المسجلة في السكيما (`Worker`) والمتوفرة في البوت بنظام البطاقات القابلة للطي (`Collapsible Card Sections`).
> 4. **تحسينات تجربة المستخدم المعتمدة لشاشة العامل:**
>    - رادار فحص التكرار اللحظي (Live Inline Duplicate Radar) للرقم القومي والهاتف أثناء الكتابة.
>    - حاسبة الراتب المرئية والاشتقاق الآلي (Visual Mini-Payslip) المدمجة تفاعلياً مع حظر الأجر اليومي.
>    - زر اقتراح اسم الشهرة الذكي بنقرة واحدة (Smart Nickname Auto-Suggest).
>    - الحفظ التلقائي للمسودة (Draft Auto-Save) محلياً لحماية البيانات الميدانية.
> 5. **بطاقة الإنجاز المتكاملة:** كود العامل الذكي، زر إرسال ترحيب واتساب المباشر، زر تسجيل عامل آخر، وزر دليل العاملين.
