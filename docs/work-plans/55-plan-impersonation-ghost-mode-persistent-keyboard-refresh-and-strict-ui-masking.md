## 🧐 تقرير النقد الاستشاري الصارم للمسودة السابقة (Adversarial Architectural Critique)

بصفتي خبيراً واستشارياً لمنظومات المحاكاة المؤسسية (Ghost Mode / RBAC Sandboxing)، قمت بتشريح المسودة الأولية تشريحاً نقدياً لاذعاً كشف عن **5 فجوات معمارية خطيرة كانت ستؤدي إلى انتكاسات وفشل تجربة المحاكاة**:

| # | موضع النقد في المسودة السابقة | العيب المعماري المكتشف | المعالجة النهائية المحصنة في هذه الخطة |
| :---: | :--- | :--- | :--- |
| **1** | **تجاهل قائمة أوامر الـ Slash (`/`):** الاقتصار على تعديل أزرار الكيبورد وإغفال قائمة الأوامر التلقائية لتليجرام. | **تسريب أوامر السوبر أدمن:** قائمة أوامر تليجرام تظل تحتفظ بأوامر `/settings`, `/jobs`, `/sites` وعند الضغط عليها يظهر رفض الوصول، مما يكسر تجربة المحاكاة. | **المزامنة اللحظية للأوامر:** استدعاء `syncUserCommandsScope(ctx.api, telegramId, targetRole)` فورياً عند بدء أو إنهاء المحاكاة لتبديل قائمة الـ Slash بالكامل وفق الدور المحاكى. |
| **2** | **تكرار الرسائل وتشويه المحادثة:** إرسال رسالة تأكيد خروج ثم رسالة ثانية لتثبيت الكيبورد عند النقر على إنهاء المحاكاة. | **تلوث الشات (Chat Noise):** إرسال رسالتين متتاليتين يربك المستخدم ويخالف ميثاق الانسيابية والنظافة. | **الانتقال الذري الموحد (Atomic Transition):** إرسال كارد استعادة الصلاحيات حاملاً كيبورد السوبر أدمن مدمجاً في نفس الرسالة دفعة واحدة وحذف الرسائل القديمة بصمت. |
| **3** | **انفصام هوية المخاطب (Identity Dissonance):** مناداة المستخدم باسم حسابه الحقيقي في تليجرام أثناء محاكاة عامل محدد. | **كسر واقعية المحاكاة:** السوبر أدمن يحاكي العامل "محمود إبراهيم" بينما البوت يرحب به قائلاً "مرحباً بك يا صالح"، مما يناقض تجربة المحاكاة الواقعية. | **التطابق الهوياتي الكامل:** عند وجود محاكاة لعامل أو مورد محدد، يتم استخراج اسمه وكوده المعتمد من `ctx.impersonatedEntity` ومخاطبته به في كروت الترحيب. |
| **4** | **سباق كاش الذاكرة L1 SWR Race Condition:** كاش الدور المحاكى في `fastCache` لمدة 120 ثانية دون تفريغ تزامني حاجب. | **قراءة الصلاحيات القديمة:** قد تستمر الطلبات التالية في قراءة الرتبة السابقة من ذاكرة RAM السيرفر لمدة تصل لدقيقتين. | **التفريغ التزامني الإلزامي:** ربط خطاف `onImpersonationChange` ليمسح مفاتيح `auth:imp` و `auth:ent` و `persistent_kb` تزامناً وبشكل مؤكد قبل إرسال رد النجاح. |
| **5** | **تموضع زر الخروج والقوائم المضمنة:** كانت المسودة الأولى تضيف زراً مضمناً داخل كارد الرسالة وزراً في السطر الأول للكيبورد. | **مخالفة رغبة المستخدم الصريحة في `/grill-me`:** المستخدم طلب أن تكون الرسائل مطابقة 100% وأن يكون زر الخروج حصراً بالسطر الأخير بالأسفل. | **الالتزام الحرفي بمخرجات `/grill-me`:** حذف زر الخروج من كروت الرسائل نهائياً، ووضعه في السطر الأخير أسفل الكيبورد السفلي. |

## 🎯 القرارات التصميمية النهائية المعتمدة

1. **الموضع الحصري لزر الخروج:**  
   يتموضع الزر `🎭 إنهاء وضع المحاكاة (العودة كمدير عام)` في **السطر الأخير (Row مستقل بأسفل الكيبورد)** أسفل كافة خيارات الدور المحاكى، لضمان تطابق الأسطر العلوية تماماً مع ما يراه صاحب الدور.
2. **عزل وتطهير القوائم المضمنة (100% Pure Inline Menus):**  
   حجب تام لكافة أزرار ووظائف السوبر أدمن (`⚙️ إعدادات النظام` و `🖥️ فتح لوحة التحكم` للأدوار غير المصرحة) في الكيبورد الثابت وفي القوائم المضمنة، وحذف أي أزرار خروج إضافية داخل الرسائل.
3. **التطابق الهوياتي الكامل (Identity Equivalence):**  
   في كارد الترحيب والقائمة الرئيسية، يتم الترحيب بالاسم والصفة والكود الوظيفي للعامل أو المورد المحاكى بدقة.
4. **المزامنة اللحظية الشاملة (Triple Sync):**  
   تحديث ثلاثي فوري متزامن عند التبديل:
   - تفريغ كاش الذاكرة L1 RAM و Redis.
   - تبديل الكيبورد السفلي (Reply Keyboard) عبر `forceRefresh = true`.
   - تبديل قائمة أوامر تليجرام الجانبية (Slash Commands Scope) وفق الدور المحاكى.

  ```typescript
  onImpersonationChange: async (telegramId: bigint, targetRole?: string) => {
    // 1. تفريغ كاش الصلاحيات اللحظي في L1 fastCache و L2 Redis
    await fastCache.invalidate(`auth:imp:${telegramId}`);
    await fastCache.invalidate(`auth:ent:${telegramId}`);
    // 2. حذف رسالة الكيبورد القديمة من الشات ثم تفريغ المعرف في Redis
    const existing = await getPersistentKeyboardMsg(telegramId);
    if (existing && bot?.api) {
      void bot.api.deleteMessage(existing.chatId, existing.messageId).catch(() => {});
    }
    await clearPersistentKeyboardMsg(telegramId);
    // 3. مزامنة قائمة أوامر تليجرام الجانبية (Slash Commands)
    if (bot?.api && targetRole) {
      void syncUserCommandsScope(bot.api, telegramId, targetRole, false).catch(() => {});
    }
  }
  ```
