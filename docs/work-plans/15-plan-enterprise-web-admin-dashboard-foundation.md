### 2️⃣ معمارية المنظومة الموحدة والربط البرمجي (Unified Headless Architecture)

تعتمد المنظومة نمط المعمارية النظيفة أحادية الاتجاه (Headless Monorepo Architecture) لضمان عدم ازدواجية الكود المحاسبي أو الأمني:

```text
                               ┌────────────────────────────────┐
                               │   packages/database (Prisma)   │
                               │  Models, Soft Delete & Hashes  │
                               └───────────────┬────────────────┘
                                               │
                               ┌───────────────┴────────────────┐
                               │   modules/* (Domain Services)  │
                               │  Workforce, Settings, Advances │
                               └───────┬────────────────┬───────┘
                                       │                │
            ┌──────────────────────────┴──┐          ┌──┴──────────────────────────┐
            │       apps/bot-server       │          │    apps/admin-dashboard     │
            │   Telegram grammY Engine    │          │    Next.js 15 App Router    │
            │  Field Interaction & Speed  │          │   Executive Web UI & BI     │
            └─────────────────────────────┘          └─────────────────────────────┘
```

#### المبادئ الهندسية الصارمة للربط:
1. **صفر تكرار لمنطق الأعمال (Zero Business Logic Duplication):**
   - كافة العمليات المحاسبية، حسابات مكافأة نهاية الخدمة، التحقق من الرقم القومي، وفحص السلف يتم استدعاؤها مباشرة من `modules/workforce` و `modules/settings`.
2. **وحدة مصدر الحقيقة لقاعدة البيانات (Single DB SSOT):**
   - كلا التطبيقين يتصلان بنواة `@alsaada/database` ذاتها، وتخضع كافة العمليات لقفل منع التزامن وسجلات التدقيق والحذف الناعم.
3. **التكامل الآمن (Session & Identity Architecture):**
   - دعم المصادقة المزدوجة: تسجيل الدخول عبر **Telegram Login Widget** الموثق بحساب التيليجرام الإداري، أو تسجيل الدخول بكلمة السر المشفرة لحسابات الإدارة العليا مع التحقق من الرتبة في جدول `User`.

### 3️⃣ هيكل الواجهات وتصميم تجربة المستخدم (Enterprise UI/UX Design System)

* **إطار العمل الأساسي:** `Next.js 15 (App Router)` مع `TypeScript 5.9+` الصارم.
* **محرك التصميم:** `Tailwind CSS 3.4+` مع دعم أصيل وتلقائي للغة العربية (`dir="rtl"`).
* **مكتبة المكونات المعتمدة:** `Shadcn UI` (مكونات مبنية على Radix UI) لضمان أقصى درجات النظافة وخفة الحجم، مع أيقونات `Lucide React`.
* **محرك الجداول والبيانات الضخمة:** `TanStack Table v8` (فلترة متعددة، فرز لحظي، ترقيم صفحات، إخفاء/إظهار الأعمدة).
* **محرك الرسوم البيانية والمؤشرات:** `Recharts / Tremor` للتقارير والرسوم البيانية.
* **تصميم متجاوب 100% (Mobile-First / Desktop-Optimized):** شريط جانبي قابل للطي، قوائم متوافقة مع شاشات الهواتف والأجهزة اللوحية، وتجربة سلسة للشاشات الكبيرة.

### 5️⃣ خريطة الشاشات والوظائف المستهدفة في مرحلة التأسيس (Target Screens & Features)

#### 🏛️ القسم الأول: موديول الإعدادات وحوكمة السوبر أدمن (`Settings & Governance Suite`)
يتضمن ربط التدفقات الـ 12 المكتملة في `modules/settings` بواجهات ويب احترافية:
1. **شاشة ملف المنظومة والشركات (`/admin/settings/company` - Flow 00.1):** عرض وتعديل بيانات الكيان المؤسسي، السجل التجاري، والبيانات العامة.
2. **مركز إدارة المواقع والمشاريع (`/admin/settings/sites` - Flow 00.2):** بطاقات تفاعلية لكافة المواقع، المشرفين المسندين لكل موقع، وإحصائيات القوى العاملة الحية.
3. **مصفوفة الوظائف والأجور (`/admin/settings/jobs` - Flow 00.3):** جداول المسميات المهنية، شرائح الرواتب واليوميات، وتحديد المخصصات.
4. **شاشة الملف الشخصي الإداري (`/admin/profile` - Flow 00.4):** بيانات الأدمن، التليجرام المرتبط، الصلاحيات الممنوحة.
5. **إسناد المشرفين للمواقع (`/admin/settings/assignments` - Flow 00.5):** مصفوفة تفاعلية لتعيين وتغيير مواقع عمل المشرفين.
6. **لوحة التحكم في وضع الشبح (`/admin/settings/ghost-mode` - Flow 00.6):** تفعيل وتعطيل وضع الشبح للسوبر أدمن واختبار الواجهات برتب مختلفة.
7. **خزينة التدقيق الجنائي وسجل الأخطاء (`/admin/settings/audit-vault` - Flow 00.7):** جداول حركات التعديل والشطب الجنائية وسجلات أخطاء النظام.
8. **مرصد القياس اللحظي وأداء النظام (`/admin/settings/telemetry` - Flow 00.8):** مؤشرات زمن استجابة البوت وقاعدة البيانات وسرعة المعالجة.
9. **إدارة ذاكرة الطوارئ والكاش (`/admin/settings/cache` - Flow 00.9):** تفريغ الكاش، تحديث القوائم اللحظية، وفحص Redis.
10. **سياسات الإشعارات والتنبيهات (`/admin/settings/notifications` - Flow 00.10):** ضبط قنوات الإشعارات وتحديد أوقات التنبيهات التلقائية.
11. **مجموعات وتوبيكات تليجرام (`/admin/settings/telegram-groups` - Flow 00.11):** خريطة توجيه التنبيهات لتوبيكات المجموعات بحسب نوع المعاملة.
12. **إدارة المستخدمين ومصفوفة الصلاحيات (`/admin/settings/users` - Flow 00.12):** ترقية وتنزيل الرتب، حظر وفك حظر المستخدمين، وفك ارتباط الحسابات.
13. **استوديو تعديل وتصحيح البيانات السريع (Doc 09 Web Studio):** واجهة جدولية تشبه الإكسيل لتعديل وتصحيح العمليات المحاسبية بالحذف الناعم والتدقيق الصارم.

#### 👷 القسم الثاني: موديول القوى العاملة والتعيينات (`Workforce & Operations Suite`)
يتضمن ربط التدفقات الـ 7 المكتملة في `modules/workforce` بواجهات ويب احترافية:
1. **دليل العاملين التفاعلي (`/admin/workforce/directory` - Flow 01.5):**
   - جدول تفاعلي كامل يدعم البحث الفوري باسم الشهرة، الاسم الرباعي، الرقم القومي، الموقع، أو المهنة.
   - تصنيف سريع بحسب الحالة: (نشط، في إجازة، موقوف، منهي خدمته).
   - عرض اسم الشهرة كاسم رئيسي كما هو معتمد دستورياً.
2. **بطاقة ملف العامل المتكاملة (`/admin/workforce/[id]` - Flow 01.2.D):**
   - كارت تفصيلي: البيانات الشخصية، المهنة، الموقع، تاريخ التعيين، الراتب، وحالة التيليجرام المرتبط.
   - تبويبات تفصيلية: (سجل الحضور ⬅️ السلف والأقساط ⬅️ العهد ومهمات الوقاية ⬅️ الإجازات ⬅️ الجزاءات والمكافآت).
   - إمكانية التعديل الفوري للبيانات من قِبل المخولين.
3. **معالج تعيين عامل جديد (`/admin/workforce/new` - Flow 01.1):**
   - نموذج ويب سلس ومتجاوب لتسجيل العامل (فحص صحة الرقم القومي المصري لحظياً، تحديد المهنة، الموقع، الأجر اليومي أو الشهري، واسم الشهرة).
4. **مركز تصفية ومخالصات إنهاء الخدمة (`/admin/workforce/clearances` - Flow 01.8):**
   - صندوق اعتماد المخالصات الميدانية المعلقة وصندوق القرارات الإدارية.
   - شاشة احتساب المخالصة المالية: تصفية الراتب المستحق، خصم السلف وتلفيات العهد والجزاءات، واختيار خطة الصرف (`فوري` أو `مع المسير`).
   - معاينة وطباعة سند المخالصة الرسمي وتوليد رابط الواتساب بنقرة واحدة.
5. **تصدير كشوفات العمال (`/admin/workforce/export` - Flow 01.4):**
   - تصدير كشوفات العاملين بصيغة Excel منسقة مع خيارات التصفية بالموقع أو المهنة.
6. **مركز طلبات الانضمام وربط الحسابات (`/admin/workforce/requests` - Flow 01.7):**
   - استعراض طلبات الانضمام المعلقة لحسابات الزوار وتأكيد ربطها بملفات العمال.

### 7️⃣ بوابات الجودة والتحقق الصارم (Definition of Done & Verification Gates)

1. **Gate G1 (Monorepo Isolation):** تطبيق الويب يقع حصراً داخل `apps/admin-dashboard` ويستورد موديولاته عبر النطاق النظيف دون تداخل.
2. **Gate G2 (Strict TypeScript):** صفر أخطاء تجميع، صفر تحذيرات `any` غير مبررة عبر `tsc --noEmit`.
3. **Gate G3 (RBAC UI Masking):** لا تظهر أي شاشة أو زر تحكم أو بيان محظور لمن لا يملك الصلاحية الدستورية المعتمدة.
4. **Gate G4 (Responsive Ergonomics):** توافق كامل ومتجاوب 100% مع شاشات الموبايل والأجهزة اللوحية وأجهزة سطح المكتب.
5. **Gate G5 (Data Integrity & Soft Delete):** كافة عمليات الحذف والتعديل تتم عبر الحذف الناعم وسجلات التدقيق الجنائية دون مساس فيزيائي بالبيانات.
6. **Gate G6 (Zero Regression):** استمرار عمل البوت وتدفقاته واختباراته بنسبة نجاح 100% دون أي تأثر.
