* **المشكلة الحالية:** لا توجد صفحة تسجيل دخول؛ أي زائر يتم تسجيل دخوله افتراضياً كسوبر أدمن عبر كوكي تجريبي.
* **الحل المعماري:**
  1. **صفحة تسجيل الدخول الرسمية ([`apps/admin-dashboard/src/app/login/page.tsx`](file:///f:/Alsaada-Smart-Bot/apps/admin-dashboard/src/app/login/page.tsx)):**
     - تصميم فاخر بهوية السعادة (اللوجو، ألوان المقاولات، ونموذج دخول عربي `dir="rtl"` متجاوب بالكامل).
  2. **مسارات تسجيل الدخول الأربعة المعتمدة:**
     - **المسار الأول (Telegram Mini App / TWA Auto-Auth):**
       * عند فتح لوحة التحكم داخل تيليجرام (موبايل/ديسكتوب)، يلتقط المكون `window.Telegram.WebApp.initData` المشفر تلقائياً ويتحقق من توقيعه بخادم الـ API عبر `HMAC-SHA256` ومفتاح `BOT_TOKEN`.
       * تسجيل دخول فوري بنقرة واحدة (Zero-Click Login) بدون إدخال أي بيانات.
     - **المسار الثاني (Telegram Login Widget - الويب الرسمي):**
       * تضمين سكريبت تيليجرام الرسمي (`https://telegram.org/js/telegram-widget.js`) مع معرف البوت.
       * عند الموافقة في تيليجرام، يتم إرسال بيانات التحقق إلى API (`/api/auth/telegram`).
       * التحقق الجنائي المشفر من صحة التوقيع عبر `HMAC-SHA256` ومفتاح الـ `BOT_TOKEN`.
     - **المسار الثالث (Telegram Bot OTP / Magic Link - من داخل البوت):**
       * أمر في البوت `/dashboard` يولد رمز دخول مؤقت (OTP مكون من 6 أرقام صالح لمدة 5 دقائق) أو رابط مباشر بنقرة واحدة.
       * يدخل المستخدم الرمز في صفحة الدخول للتحقق الفوري.
     - **المسار الرابع (الاعتماد الإداري للأدمن - Credentials Fallback):**
       * إمكانية الدخول برقم التيليجرام أو الكود الوظيفي وكلمة المرور المشفرة للوصول السريع أثناء انقطاع شبكة تيليجرام.
  3. **حارس المسارات وميدلوير الجلسات ([`src/middleware.ts`](file:///f:/Alsaada-Smart-Bot/apps/admin-dashboard/src/middleware.ts)):**
     - حماية كافة مسارات `/admin/*`؛ إعادة توجيه المستخدم غير المسجل فورياً إلى `/login`.
     - حفظ توكن الجلسة المشفر في كوكي آمن (`HttpOnly`, `SameSite=Lax`, `Secure`).
     - جلب بيانات المستخدم الحقيقية من جدول `User` في قاعدة البيانات (الاسم، المعرف، الرتبة، الموقع المسند).
     - زر صريح في القائمة والهيدر لتسجيل الخروج (`[ 🚪 تسجيل الخروج ]`) يمسح الجلسة فورياً.
